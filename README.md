# Student Management System

A Flask-based Student Management System with separate Teacher and Student portals.

## Teacher Login

Username: `teacher`

Password: `admin`

## Features

### Teacher Portal

* Add Student
* Manage Attendance
* Update Marks
* View Students
* Delete Student

### Student Portal

* View Attendance
* View Subject Marks
* View Profile Information

## Technologies Used

* Python
* Flask
* SQLite
* HTML
* CSS
* JavaScript

## How to Run

1. Clone the repository.
2. Install Flask:
   pip install flask
3. Run:
   python app.py
4. Open:
   http://127.0.0.1:5000

## Notes

* The application uses SQLite (`students.db`) for data storage.
* Teacher credentials are hardcoded for demonstration purposes.
* Student login uses the student's roll number.
